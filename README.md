# Custom AI Bot (ChatGPT-Codex)

Sam is an in-game companion for Factorio. He builds the It Begins starter factory and the Jump Start Base, or takes orders from the **Напарник** panel. The built-in plans and orders run inside Factorio.

## Installation

Install [Custom AI Bot from the Factorio Mod Portal](https://mods.factorio.com/mod/codex-companion). Requires Factorio 2.1.24 or later in the 2.1 series.

To run the source locally, copy this repository into a folder named `codex-companion_1.1.4` in your Factorio mods directory. Use the version in `info.json` when naming the folder for future releases.

## Optional AI connection on Windows

Host a local multiplayer game, open **Напарник → Данные для подключения**, and copy the prompt into Codex or another local MCP-capable agent. At first setup use **Ctrl+C**. The prompt includes the source for a Windows bridge that the agent creates on your PC. The bridge connects over local RCON.
